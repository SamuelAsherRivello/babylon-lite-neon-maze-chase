# Security Policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue.

Use GitHub private vulnerability reporting when it is enabled for this
repository. If it is unavailable, contact the repository owner through a
verified private contact method listed in the README or repository profile.

Include a concise description, affected version or revision, reproduction
steps, impact, and any proposed mitigation. Do not include passwords, tokens,
private keys, seed phrases, recovery material, or other credentials.

## Handling sensitive information

Never commit secrets, local environment files, production data, private keys,
or recovery material. Use safe placeholders in examples and enter real values
only in the target service or local environment.
